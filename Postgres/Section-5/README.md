# SQL Practice – Aggregate Functions and Grouping

## Introduction

This section explores SQL aggregate functions and grouping techniques through practical exercises involving books, authors, and phone manufacturers.

## Exercise Summary

### Exercise 1 – Practice For Grouping and Aggregating
Grouped books by author ID and calculated the number of books written by each author.

### Exercise 2 – Grouping With a Join!
Joined the authors and books tables to display author names along with their respective book counts.

### Exercise 3 – Practice Yourself Some Having
Calculated the total revenue for each phone manufacturer and selected only those exceeding the specified revenue limit.

## SQL Topics Covered

- GROUP BY
- COUNT()
- SUM()
- INNER JOIN
- HAVING
- Aggregate calculations
- Filtering grouped records

- PostgreSQL

Practised summarizing database records, calculating grouped totals, and applying conditions to aggregate results.
