# Section 31 – Version-Controlled Database Evolution with Schema Migrations

## Overview
Explored structured workflows and tooling for tracking, deploying, and rolling back incremental PostgreSQL schema changes over an application's lifecycle.

## Topics Covered
- Real-World Motivation and Workflow Behind Schema Migrations
- Anatomy and Structure of Forward (`UP`) and Rollback (`DOWN`) Migration Files
- Key Team Collaboration and Deployment Problems Solved by Migrations
- Evaluating Popular Schema Migration Libraries and Tooling
- Environment Prerequisites and Node.js Runtime Setup
- Initializing a Migration-Enabled Project Workspace
- Generating and Authoring Custom Schema Migration Scripts
- Executing Forward Migrations and Testing Rollback Reversions
- Iterating on Schema Changes by Generating and Applying a Second Migration

## Technology
- PostgreSQL
- SQL
- Node.js

## Learning Outcome
Developed the ability to manage iterative database changes reliably using version-controlled migration scripts, forward deployments, and safe rollbacks.
