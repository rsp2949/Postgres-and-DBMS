# Section 22 – PostgreSQL Storage Engine and Internal Architecture

## Overview
Explored the physical storage mechanisms of PostgreSQL, examining how records are persisted on disk and how internal layouts impact query performance.

## Topics Covered
- Foundations of Query Performance and Disk I/O
- Locating Physical Data Directories in PostgreSQL
- Understanding Heaps, Pages (Blocks), and Tuples
- Examining Internal Block and Page Data Organization
- Analyzing Heap File Structures and Record Storage

## Technology
- PostgreSQL
- SQL

## Learning Outcome
Developed a clear understanding of PostgreSQL's low-level storage architecture, including heap files, 8KB pages, and tuple organization, and their role in database efficiency.
