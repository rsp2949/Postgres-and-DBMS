# Section 16 – Modeling Social Interactions and Reaction Systems

## Overview
Explored relational modeling strategies for implementing user engagement features such as likes and multi-type reactions using polymorphic design patterns.

## Topics Covered
- Core Functional Requirements for Engagement Tracking
- Architecting a Scalable Like Feature
- Expanding to Multi-Type Reaction Models
- Implementing Polymorphic Associations in Relational Databases
- Evaluating Alternative Schema Designs (Separate Tables vs. Exclusive Arcs)
- Selecting the Optimal Pattern Based on Trade-Offs

## Technology
- PostgreSQL
- SQL

## Learning Outcome
Developed the ability to evaluate trade-offs and architect flexible database schemas for user reactions across multiple content types.
