# SQL Practice – Exercises 3 to 7

## About

This folder includes SQL queries completed while practising PostgreSQL through the Udemy SQL course. These exercises focus on retrieving, filtering, modifying, and deleting table records.

## Exercise Summary

| Exercise | Topic | SQL Concepts |
|---|---|---|
| 3 | Practicing WHERE Statements | WHERE, comparison operators |
| 4 | A More Challenging WHERE | AND/OR conditions |
| 5 | Trying Calculations in WHERE Clauses | Arithmetic operations, filtering |
| 6 | Try Updating Records in a Table | UPDATE, SET |
| 7 | Practice Deleting Records | DELETE, WHERE |

## Skills Practised

- Writing queries to retrieve specific records.
- Applying conditions to filter table data.
- Using logical operators in filtering conditions.
- Calculating values directly within SQL queries.
- Modifying existing records in a table.
- Removing records based on specified conditions.

Gained practical experience in writing SQL queries and performing common database operations, including filtering, calculations, updating, and deleting records.
