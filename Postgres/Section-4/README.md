# SQL Practice – Working with Joins

## Introduction

This section focuses on combining data from multiple tables in a relational database. The exercises use a book publishing database containing authors, books, and reviews.

## Exercise Summary

### Exercise 1 – Practice Joining Data
Used INNER JOIN to display each book alongside its corresponding author.

### Exercise 2 – Joins, Joins, Join!
Used LEFT JOIN to include every author, even when no associated book exists.

### Exercise 3 – Three Way Exercise
Combined the books, authors, and reviews tables to retrieve book titles, author names, and review ratings while applying the required matching conditions.

## SQL Topics Covered

- INNER JOIN
- LEFT JOIN
- Multiple table joins
- ON conditions
- Foreign key relationships
- Matching records across tables

## Tools Used

- PostgreSQL
- SQL
- GitHub

## Learning Outcome

Understood how different join operations work and how to retrieve related data while handling matching and non-matching records across database tables.
