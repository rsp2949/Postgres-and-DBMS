# Section 18 – Implementing Hashtag Taxonomy and User Profile Metrics

## Overview
Explored relational database modeling for content categorization using hashtags alongside expanding user tables with profile metadata and aggregate metrics.

## Topics Covered
- Architecting a Scalable Hashtag Classification Model
- Structuring Normalized Tables for Unique Hashtags
- Integrating Hashtag Join Tables into Existing Post Schemas
- Extending User Tables with Additional Profile Attributes
- Evaluating Approaches for Tracking Follower and Post Counts

## Technology
- PostgreSQL
- SQL

## Learning Outcome
Developed the ability to model many-to-many content tagging relationships and manage derived user statistics within PostgreSQL.
