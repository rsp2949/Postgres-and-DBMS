# Section 19 – Modeling Social Graphs and User Follower Relationships

## Overview
Explored self-referential relational patterns in PostgreSQL to represent directional user connections and social network hierarchies.

## Topics Covered
- Architecting a Scalable User-Following Mechanism
- Mapping Directional Social Graph Relationships (Leader vs. Follower)
- Structuring Self-Referential Join Tables and Preventing Duplicate Follows

## Technology
- PostgreSQL
- SQL

## Learning Outcome
Developed the ability to model asymmetric user relationships and organize social graph data cleanly within a relational database.
