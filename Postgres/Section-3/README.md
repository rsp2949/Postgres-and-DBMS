# Section 3 – Creating and Using Foreign Keys

## Overview

This exercise focuses on creating relationships between database tables using foreign keys in PostgreSQL.

A naval shipping database was designed with two tables: `boats` and `crew_members`. Each boat can have multiple crew members.

## Exercise Details

- Created the `boats` table with an ID and boat name.
- Inserted two boat records.
- Created the `crew_members` table.
- Added the `boat_id` column to reference the boats table.
- Inserted three crew member records.
- Retrieved crew members associated with boat ID 1.

## Concepts Practised

- Creating relational tables.
- Primary keys.
- Foreign key constraints.
- REFERENCES clause.
- Inserting records.
- Filtering records using WHERE.

## Technology Used

- PostgreSQL
- SQL
- GitHub

## Learning Outcome

Learned how to establish relationships between tables using foreign keys and retrieve related records through SQL queries.
