# Section 9 – SQL Subqueries

## Overview

This section focuses on practising SQL subqueries using PostgreSQL. The exercises cover nested queries and the use of subqueries in different parts of SQL statements.

## Topics Covered

1. Embedding subqueries in SELECT statements.
2. Using SELECT statements without a FROM clause.
3. Filtering records using subqueries.
4. Comparing values with subquery results.
5. Using subqueries in the FROM clause.

## SQL Concepts

- SELECT and nested SELECT statements
- Aggregate functions: MAX, MIN, AVG
- WHERE conditions
- ALL operator
- GROUP BY
- Column aliases
- Scalar subqueries

## Tools Used

- PostgreSQL
- SQL
- GitHub
