# SQL Practice – Grouping and Inner Joins

## Introduction

This section contains SQL exercises based on an e-commerce dataset. The tasks focus on summarizing order information and retrieving related user and order details.

## Exercise Summary

### Exercise 1 – Group By Review
Used GROUP BY and COUNT() to calculate how many orders were paid and unpaid.

### Exercise 2 – Inner Join Review
Joined the users and orders tables using their related IDs to display each user's first name, last name, and payment status.

## SQL Topics Covered

- GROUP BY
- COUNT()
- INNER JOIN
- ON clause
- Table relationships
- Aggregate queries

Practised grouping database records and combining information from related tables through SQL queries.
