# Section 20 – End-to-End Social Media Schema Implementation

## Overview
Applied relational modeling concepts in PostgreSQL to build out a complete, production-style social platform schema with enforced data integrity rules.

## Topics Covered
- Defining Core Tables with Custom Validation Checks
- Building the Posts Table and Media Constraints
- Structuring Threaded Comments and Foreign Key References
- Implementing Polymorphic Likes and Engagement Tables
- Setting Up Separate Photo Tagging and Caption Mention Tables
- Constructing Hashtag Registries, Junction Tables, and Follower Graphs

## Technology
- PostgreSQL
- SQL

## Learning Outcome
Gained hands-on experience translating complex social network requirements into normalized tables, constraints, and multi-table relationships in PostgreSQL.
