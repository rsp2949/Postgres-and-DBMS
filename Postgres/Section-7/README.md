# Section 7 – SQL Grouping and Aggregation

## Overview

This section focuses on practising SQL queries involving grouping, aggregate functions, joins, and result ordering using PostgreSQL.

## Topics Covered

- GROUP BY and aggregate functions
- COUNT and HAVING
- GROUP BY with JOIN
- INNER JOIN and table relationships
- Finding manufacturers with the highest revenue
- ORDER BY, LIMIT, and OFFSET

## Skills Practised

- Grouping data based on common values.
- Counting records and analysing grouped results.
- Filtering groups using HAVING.
- Joining related tables to retrieve combined information.
- Calculating and comparing total revenue.
- Sorting and restricting query results.

## Tools Used

- PostgreSQL
- SQL
- GitHub

## Outcome

Developed practical experience in writing SQL queries for data grouping, aggregation, joins, and result management.
