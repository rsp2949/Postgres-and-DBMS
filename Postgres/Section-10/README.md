# Section 10 – DISTINCT

## Overview

This section covers the use of the SQL `DISTINCT` keyword to retrieve unique values from a table.

## Exercise

**Some Practice with Distinct**

Write a query to find the number of unique phone manufacturers in the `phones` table.

## Concepts Covered

- `DISTINCT` – Retrieves unique values.
- `COUNT()` – Counts the number of values.
- `COUNT(DISTINCT column)` – Counts unique values in a column.

## Technologies

- PostgreSQL
- SQL

## Learning Outcome

Gained practical experience in identifying and counting unique records using SQL aggregate functions.
