# Section 17 – Architecting User Mentions, Tagging, and Post Metadata

## Overview
Explored relational schema patterns for extending social posts with geolocation data, captions, and distinct user-tagging mechanisms across media and text.

## Topics Covered
- Extending Core Post Schemas with Supplementary Metadata
- Structuring Geolocation Coordinates and Text Captions
- Comparing Spatial Photo Mentions and Text-Based Caption Mentions
- Designing Separate Tables for Photo Tags vs. Caption Tags
- Handling Tag Modifications and Lifecycle Updates

## Technology
- PostgreSQL
- SQL

## Learning Outcome
Developed the ability to differentiate and model context-specific tagging systems alongside rich post metadata in relational databases.
